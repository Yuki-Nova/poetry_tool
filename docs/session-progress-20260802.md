## 一、押韵校验引擎修复（rhymeChecker / patternMatcher）

### 1.1 押韵检查三处问题（`3edf623`）

| 问题 | 根因 | 修复 |
|---|---|---|
| **行尾标点吞韵脚** | `extractRhymeChars` 取 `line[line.length-1]`，用户输入「床前明月光，」时最后是标点被过滤 → 韵脚丢失 | 从行尾**跳过标点**取最后一个有效字符作为韵脚 |
| **词牌转韵误报** | `checkRhyme` 强制所有韵脚同部，但 30/153 词牌（菩萨蛮/虞美人/西江月等）仄平交替转韵是合法 | 按**连续同 rhymeType 分段**（run-length grouping）：段内同部、段间不比较 |
| **格律 span 变体丢字** | 源站 `ze2/ping2/ze3`（下半阕颜色变体）未被 `"ze" in cls` 匹配 → 韵脚字跳过、字数少 1、韵脚类型误判 | parse.py 改用前缀正则 `^ping\d*$` / `^ze\d*$` |

**验证**：虞美人逐组换韵合法（了/少 第八部 → 风/中 第一部 → 在/改 第五部 → 愁/流 第十二部）；全库 `length != len(pattern)` 归零。

### 1.2 多音字跨部误报（`d9c00ae`）

**用户场景**：李清照《声声慢》「识」「积」被误报属「第三部」，但全词押入声第十七部。

**根因**：词林正韵把多音字收入多个韵部——「识」读 shí（入声职韵）→ 第十七部、读 zhì（去声志韵）→ 第三部；「积」同理（jī 入声昔韵 / jì 去声寘韵）。`getRhymeGroup` 线性扫描返回**首个匹配**（第三部在前）→ 入声读法被误判。全库共 **153 个多部字**（145 个双部、8 个三部）。

**修复**：
- 新增 `getRhymeGroups(char, rhymeBook)` 返回全部匹配韵部
- `checkRhyme` 段内基准改为**多数派投票**（非多音字韵脚占多数时以其韵部为基准），多音字只要含基准即合法
- 多音字不掩盖真实出韵（段内真不同部仍报错）

**验证**：李清照 10 韵脚（觅戚息急识积摘黑滴得）多数派=第十七部 → 判合法；测试 43 → **46**。

## 二、爬虫数据链路修复（longyusheng_crawler）

### 2.1 例词编码菱形码（`92227a1`）

**用户场景**：例词作者「鹿虔�」菱形码。

**根因**：源站 meta 声明 `charset=gb2312` 但实际含 GBK/GB18030 扩展字符（生僻字「扆」等），`decode("gb2312", errors="replace")` 把 94/153 页替换为 U+FFFD。

**修复**：`fetch.py` 改用 **gb18030** 解码（GB2312 超集）→ 全量重抓 153 页 → 重导数据库。「鹿虔扆」完整恢复，U+FFFD 清零。

### 2.2 领字标记 lingge（`9dad064`）

**用户场景**：《水龙吟》定格/变格末句「念」「料」「也」领字平仄未爬入。

**根因**：源站用 `<span class="lingge">仄/平</span>` 标记领字（加粗下划线样式），**109 处 / 37 词牌**（兰陵王/木兰花/水龙吟/沁园春/八声甘州等），parse.py 忽略 → 领字平仄丢失。

**修复**：`tokenize_line` 解析 `lingge` span 内容（平/仄/中）。

**验证**：水龙吟定格/变格末三句 = `仄平平仄仄，中平中仄，仄平平仄` ✅ 与权威格律完全一致。

### 2.3 增韵标记 zeng（`9da5e62`）

**用户场景**：《水龙吟》第 13 句第 6 字「见」报「应为 ? 声」——模板该位置未定义。

**根因**：源站用 `<span class="zeng">仄</span>` 标记增韵韵脚（紧跟 `yun0`，如「中仄中平中仄（增韵）」），**33 处 / 8 词牌**（鹊桥仙/水龙吟/高阳台/齐天乐等），parse.py 忽略 → 增韵句字数少 1 → 用户输入第 6 字超出模板。

**修复**：`tokenize_line` 解析 `zeng` span 内容（平/仄/中）。注意区分：格律谱中 zeng 是增韵韵脚（须解析），例词 ces 中的 zeng 是加粗字（清洗时已剥离，不影响）。

**验证**：水龙吟定格/变格第 13 句 len 5→**6**（`中仄中平中仄`）；全库 0 异常。

## 三、编辑器韵脚视觉升级（EditorHighlightLayer / PoetryIDE / App.vue）

### 3.1 韵脚淡黄高亮 + 出韵红色标记（`696b93f` + `bf11a07`）

| 状态 | 样式 |
|---|---|
| 正确韵脚（isRhyme） | **淡黄底** `#fdf6e3` + 金字 + 细金框 |
| 错韵（韵脚声调不符 rhyme-warn） | **红底红框**（`t-rhyme-err`，与出韵一致标红） |
| 出韵 / 未收录 | **红底红框 + 红色波浪线**（`t-rhyme-out`，最高优先） |

**关键实现**：
- 高亮层以 `r.isRhyme` 判定韵脚（诗体 pattern 韵脚位是平/仄 status=ok、词牌标「韵脚」status=ok-rhyme，统一处理）
- `PoetryIDE` 接收 `rhymeResult`，将出韵/未收录错误定位到韵脚列并透传高亮层
- `checkRhyme.errors` 携带 line + char → `rhymeErrorList` computed 换算为 `{line, col}`

### 3.2 信息面板与格律预览头部对齐（`92227a1` 附带）

`PatternSelector` 移出双栏容器改为全宽横条，左列从 PatternPreview 开始 → `CipaiInfoPanel` 与预览头部自然等高对齐（≤900px 仍堆叠单栏）。
